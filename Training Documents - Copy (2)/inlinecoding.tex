In today's digital world, creating interactive and visually appealing content for the web requires
knowledge of three core technologies: HTML, CSS, and JavaScript.
These three building blocks work together to form the structure, style, and interactivity of web pages and
applications.

  It organizes the main parts of the page, such as text, images, buttons, questions,

    \textbf{Cascading Style Sheets}

  It changes visual details such as colors, fonts, spacing, borders, layout,

\section*{\Bitter\textcolor{naranja}{Understanding the Basic Syntax}}
\label{sec:basic-syntax}

Before we start building small activities, it helps to understand the basic pattern behind the code.
We do not need to memorize everything. Instead, we want to recognize what each part is doing so we can read AI-generated code, adjust it when needed, and explain what we want more clearly.

\vspace{0.3cm}

\phantomsection
\subsection*{\Bitter\textcolor{naranja}{HTML Syntax: Creating the Parts}}
\label{subsec:html-syntax}

We can think of HTML as the part of the code that answers the question:
\textbf{What do we want to place on the screen?}

For example, if we want a paragraph, a button, an image, a table, a choice, or a feedback box, HTML is what creates those pieces.
CSS can style them later, and JavaScript can make them respond, but HTML gives us the actual elements to work with.

Most HTML elements are written using \textbf{tags}.
A tag tells the browser what type of element we are creating.

\vspace{0.2cm}

\begin{lstlisting}
(*@\htmltag{<p>}@*)(*@\codetext{This is a paragraph.}@*)(*@\htmltag{</p>}@*)
\end{lstlisting}

In this example, \inlinehtmltag{<p>} opens the paragraph, and \inlinehtmltag{</p>} closes it.
The text between the opening and closing tags is \textbf{the content that appears on the page.}

\vspace{0.2cm}

\begin{lstlisting}
(*@\htmltag{<tag>}@*)(*@\textbf{Content that appears on the page}@*)(*@\htmltag{</tag>}@*)
\end{lstlisting}

\vspace{0.4cm}

\textbf{\Bitter\textcolor{naranja}{Common HTML Tags for Small Activities}}

\vspace{0.1cm}

\begin{itemize}[leftmargin=1.2cm, itemsep=4pt]
  \item \inlinehtmltag{<div>} creates a general block or container. We often use it to group parts of an activity.
  \item \inlinehtmltag{<h1>}, \inlinehtmltag{<h2>}, \inlinehtmltag{<h3>} create headings with different sizes.
  \item \inlinehtmltag{<p>} creates a paragraph of text.
  \item \inlinehtmltag{<button>} creates a clickable button.
  \item \inlinehtmltag{<input>} creates a field or choice we can interact with, such as a text box, checkbox, or radio button.
  \item \inlinehtmltag{<label>} adds readable text beside an input. It helps us understand what each choice means.
  \item \inlinehtmltag{<img>} adds an image.
  \item \inlinehtmltag{<table>} creates a table for rows and columns.
  \item \inlinehtmltag{<tr>} creates a table row.
  \item \inlinehtmltag{<td>} creates a table cell.
  \item \inlinehtmltag{<span>} targets a small piece of text inside a line.
  \item \inlinehtmltag{<br>} creates a line break.
\end{itemize}

\vspace{0.4cm}

Here is a small example that uses a few common HTML tags together.
This example only uses HTML, so it creates the content, but it does not style it yet.

\vspace{0.2cm}

\noindent

In this example:

\begin{enumerate}[leftmargin=1.2cm, itemsep=4pt]
  \item The \inlinehtmltag{<div>} groups the activity into one block.
  \item The \inlinehtmltag{<h2>} creates the heading.
  \item The \inlinehtmltag{<p>} creates the question text.
  \item The \inlinehtmltag{<input>} creates each answer choice as a radio button.
  \item The \inlinehtmltag{<label>} adds the visible answer text beside each radio button.
  \item The \inlinehtmltag{<br>} moves each answer choice to a new line.
  \item The \inlinehtmltag{<button>} creates something we can click.
  \item The \inlinehtmltag{<p>} with id \inlineattrvalue{feedback} creates an empty paragraph where we can later add feedback messages.
\end{enumerate}

\vspace{0.3cm}

When the browser reads plain HTML, it displays the elements in their default layout.

\begin{itemize}[leftmargin=1.2cm, itemsep=4pt]
  \item The browser reads the code in the order it is written, from \textbf{top to bottom}.
  \item Some elements, such as \inlinehtmltag{<div>}, \inlinehtmltag{<h2>}, and \inlinehtmltag{<p>}, are \textbf{block-level elements}.
  \item Block-level elements usually start on a \textbf{new line}, so they appear under each other.
  \item Other elements, such as \inlinehtmltag{<input>}, \inlinehtmltag{<label>}, and \inlinehtmltag{<button>}, are \textbf{inline-level elements}.
  \item Inline-level elements usually stay on the same line and render from \textbf{left to right}, as long as there is enough space.
  \item However, the \inlinehtmltag{<br>} tag creates a line break, so it forces the next element to move to the next line.
\end{itemize}

In our example, each answer choice uses an \inlinehtmltag{<input>} and a \inlinehtmltag{<label>}. These two appear beside each other because they are inline-level elements. But after each label, we added \inlinehtmltag{<br>}, so the next answer choice starts on a new line.

\vspace{0.2cm}

\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Attention Please!}}

  The \inlinehtmltag{<br>} tag is different from tags like \inlinehtmltag{<p>} or \inlinehtmltag{<div>} because it does not hold content.
  It only creates a line break. That is why we write \inlinehtmltag{<br>} by itself, without a closing tag.
\end{attentionbox}

This simple activity appears at the top-left of the browser without any special spacing, color, or positioning.
This is where CSS becomes useful. HTML creates the parts, but CSS helps us move them, style them, space them, and make the activity look more polished.

\vspace{0.4cm}

\textbf{\Bitter\textcolor{naranja}{Tag Attributes: Adding Extra Details}}

\vspace{0.1cm}

Some HTML tags can include extra information called \textbf{attributes}.
Attributes help describe how an element should behave, how it should be identified, or how it should connect to other parts of the activity.

We write attributes \textbf{inside the opening tag.}

\vspace{0.2cm}

\begin{lstlisting}
(*@\htmltag{<input}@*) (*@\attrname{class}@*)=(*@\attrvalue{"answer-input"}@*) (*@\attrname{type}@*)=(*@\attrvalue{"radio"}@*) (*@\attrname{id}@*)=(*@\attrvalue{"html"}@*) (*@\attrname{name}@*)=(*@\attrvalue{"language"}@*) (*@\attrname{value}@*)=(*@\attrvalue{"html"}@*)(*@\htmltag{>}@*)
\end{lstlisting}

In this example, the \inlinehtmltag{<input>} tag creates a choice.
The attributes give that choice more meaning:

\begin{itemize}[leftmargin=1.2cm, itemsep=4pt]
  \item \textbf{\inlineattr{class}=\inlineattrvalue{"answer-input"}} gives the input a class name we can style with CSS.
  \item \textbf{\inlineattr{type}=\inlineattrvalue{"radio"}} tells the browser this input is a radio button.
  \item \textbf{\inlineattr{id}=\inlineattrvalue{"html"}} gives this specific choice a unique identifier.
  \item \textbf{\inlineattr{name}=\inlineattrvalue{"language"}} groups the answer choices together.
  \item \textbf{\inlineattr{value}=\inlineattrvalue{"html"}} stores the value of the selected answer.
\end{itemize}

A simple way to remember this is: the \textbf{tag} creates the element, and the \textbf{attributes} give it extra details.

\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Attention Please!}}

  Different HTML tags can have different attributes, and some attributes are valid for certain tags but not for
  others. For example, the \inlineattr{type} attribute is valid for \inlinehtmltag{<input>}
  but not for \inlinehtmltag{<p>}.
\end{attentionbox}


\vspace{0.3cm}


\phantomsection
\subsection*{\Bitter\textcolor{naranja}{CSS Syntax: Styling the Parts}}
\label{subsec:css-syntax}

After HTML creates the parts of the activity, CSS helps us decide how those parts should look.
We can think of CSS as the part of the code that answers the question:
\textbf{How should this appear on the screen?}

CSS can control colors, spacing, borders, fonts, size, alignment, and layout.
This is why plain HTML can look very simple at first, but the same HTML can look polished once CSS is added.

\vspace{0.2cm}

CSS usually follows this pattern:

\begin{lstlisting}
(*@\cssselector{selector}@*) (*@\csspunct{\{}@*)
  (*@\cssprop{property}@*): (*@\cssvalue{value}@*);
(*@\csspunct{\}}@*)
\end{lstlisting}

\begin{enumerate}
  \item The \textbf{selector} chooses the HTML element we want to style.
  \item The \textbf{property} tells the browser what visual feature we want to change.
  \item The \textbf{value} tells the browser how we want that feature to look.
\end{enumerate}

\vspace{0.3cm}

\textbf{\Bitter\textcolor{naranja}{A Small CSS Example}}

\vspace{0.1cm}

\begin{lstlisting}
(*@\cssselector{.activity-card}@*) (*@\csspunct{\{}@*)
  (*@\cssprop{background-color}@*): (*@\cssvalue{\#ffefe9}@*);
  (*@\cssprop{border}@*): (*@\cssvalue{2px solid \#ff4500}@*);
  (*@\cssprop{border-radius}@*): (*@\cssvalue{12px}@*);
  (*@\cssprop{padding}@*): (*@\cssvalue{16px}@*);
  (*@\cssprop{width}@*): (*@\cssvalue{300px}@*);
(*@\csspunct{\}}@*)
\end{lstlisting}

In this example, \inlinecssselector{.activity-card} selects the HTML element with the class name \inlineattrvalue{activity-card}.
The lines inside the curly braces style that activity card.

\begin{itemize}[leftmargin=1.2cm, itemsep=4pt]
  \item \inlinecssprop{background-color} changes the background color.
  \item \inlinecssprop{border} adds a border around the card.
  \item \inlinecssprop{border-radius} rounds the corners.
  \item \inlinecssprop{padding} adds space inside the card.
  \item \inlinecssprop{width} controls how wide the card is.
\end{itemize}

\vspace{0.3cm}


\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Attention Please!}}

  The reason CSS knows which part to style is because the HTML has an attribute called \textbf{\inlineattr{class}}.

  \begin{lstlisting}
(*@\htmltag{<div}@*) (*@\attrname{class}@*)=(*@\attrvalue{"activity-card"}@*)(*@\htmltag{>}@*)
\end{lstlisting}

  Then CSS uses that class name with a dot:

  \begin{lstlisting}
(*@\cssselector{.activity-card}@*) (*@\csspunct{\{}@*)
  (*@\cssprop{padding}@*): (*@\cssvalue{16px}@*);
(*@\csspunct{\}}@*)
\end{lstlisting}

  The dot before \inlinecssselector{.activity-card} means we are selecting a class.
  So, \inlineattr{class}=\inlineattrvalue{"activity-card"} in HTML connects to \inlinecssselector{.activity-card} in CSS.

  Other selectors can target elements by their tag name, id, or other attributes.
  For now, we are using class names because they are a common and simple way to style specific parts of an activity.

  \vspace{0.15cm}

  Here is the basic idea:

  \begin{lstlisting}
(*@\cssselector{.activity-card}@*) (*@\csspunct{\{}@*)(*@\csspunct{\}}@*) (*@\csscomment{/* targets class="activity-card" */}@*)
(*@\cssselector{\#main-title}@*) (*@\csspunct{\{}@*)(*@\csspunct{\}}@*) (*@\csscomment{/* targets id="main-title" */}@*)
(*@\cssselector{button}@*) (*@\csspunct{\{}@*)(*@\csspunct{\}}@*) (*@\csscomment{/* targets every <button> tag */}@*)
\end{lstlisting}

\end{attentionbox}

\vspace{0.4cm}

\textbf{\Bitter\textcolor{naranja}{Common CSS Properties We May Use}}

\vspace{0.1cm}

\begin{itemize}[leftmargin=1.2cm, itemsep=4pt]
  \item \inlinecssprop{color} changes the text color.
  \item \inlinecssprop{background-color} changes the background color.
  \item \inlinecssprop{font-size} changes the size of the text.
  \item \inlinecssprop{font-family} changes the style of the font.
  \item \inlinecssprop{padding} adds space inside an element.
  \item \inlinecssprop{margin} adds space outside an element.
  \item \inlinecssprop{border} adds a border around an element.
  \item \inlinecssprop{border-radius} rounds the corners.
  \item \inlinecssprop{text-align} aligns text to the left, center, or right.
  \item \inlinecssprop{display}: \inlinecssvalue{flex} lets us arrange items more easily.
  \item \inlinecssprop{justify-content} controls horizontal alignment when we use flex.

\subsection*{\Bitter\textcolor{naranja}{JavaScript Syntax: Adding Behavior}}
\label{subsec:javascript-syntax}

JavaScript is a coding language that runs in the browser.
It helps the browser do more than just show text and images.

With JavaScript, we can target different parts of a web page and change what happens on the screen.
For example, JavaScript can:

\begin{itemize}
  \item change text after someone clicks a button,
  \item show or hide feedback,
  \item check if an answer is correct,
  \item change colors or classes,
  \item respond when someone types, clicks, drags, or selects something.
\end{itemize}

In simple terms, HTML creates the parts, CSS styles the parts, and JavaScript helps the page \textbf{react}.
\vspace{0.3cm}

Before we go into the code, it is important to understand what a \textbf{function} is in coding.

\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Attention Please!}}

  A function is a set of instructions that we want to run together.
  Instead of writing the same instructions many times, we can place them inside one function and reuse that function when we need it.
\end{attentionbox}

A simple JavaScript function follows this syntax:

\begin{lstlisting}
(*@\jskeyword{function}@*) (*@\jsfunction{functionName}@*)(*@\jspunct{()}@*) (*@\jspunct{\{}@*)
  (*@\jscomment{// function instructions go here}@*)
(*@\jspunct{\}}@*)
\end{lstlisting}

\begin{itemize}
  \item The \inlinejskeyword{function} keyword tells JavaScript that we are creating a reusable action.
  \item The \inlinejsfunction{functionName} tells us what the action is called.
  \item The \inlinejsmethod{()} are part of the function structure. They can also hold parameters, which are extra pieces of information we can pass to the function when we run it.
  \item The curly braces \inlinejsmethod{\{\}} tell JavaScript where the function starts and ends. The code inside the curly braces is what gets executed when we run the function.
\end{itemize}

\vspace{0.3cm}

\textbf{\Bitter\textcolor{naranja}{A Very Simple Function Example}}

\vspace{0.1cm}

Here is a very simple JavaScript function:

\begin{lstlisting}
(*@\jskeyword{function}@*) (*@\jsfunction{sayHello}@*)(*@\jspunct{()}@*) (*@\jspunct{\{}@*)
  (*@\jsmethod{alert}@*)(*@\jspunct{(}@*)(*@\jsstring{"Hello!"}@*)(*@\jspunct{)}@*);
(*@\jspunct{\}}@*)
\end{lstlisting}

This function is called \inlinejsfunction{sayHello}.
When the function runs, it shows a small message that says \inlinejsstring{"Hello!"} on the browser screen.

\vspace{0.2cm}

To run the function, we call it by writing its name followed by parentheses:

\begin{lstlisting}
(*@\jsfunction{sayHello}@*)(*@\jspunct{()}@*);
\end{lstlisting}

\textbf{\Bitter\textcolor{naranja}{Built-in Browser Tools We May See}}

\vspace{0.1cm}

When we write JavaScript for a web activity, we often need it to find something on the page first.
For example, JavaScript may need to find a button, an answer choice, or a feedback message.

To do this, it uses built-in browser tools such as \inlinejsobject{document}, \inlinejsmethod{querySelector()}, and \inlinejsmethod{getElementById()}.

\vspace{0.2cm}

Here are a few common ones we may see:

\begin{itemize}
  \item \inlinejsobject{document} represents the web page that the browser is showing.
  \item \inlinejsmethod{querySelector()} finds the first HTML element that matches a CSS selector.
  \item \inlinejsmethod{getElementById()} finds one HTML element by its unique \inlineattr{id}.
  \item \inlinejsmethod{getElementsByClassName()} finds HTML elements that share the same \inlineattr{class}.
  \item \inlinejsobject{value} lets JavaScript read the value stored inside an input.
  \item \inlinejsobject{checked} tells JavaScript whether a radio button or checkbox is selected.
\end{itemize}

This is where we use an \inlinejskeyword{if} and \inlinejskeyword{else} block.

An \inlinejskeyword{if} block checks a condition.
If the condition is true, one set of instructions runs.
If the condition is not true, the \inlinejskeyword{else} block runs instead.

\vspace{0.2cm}

The basic structure looks like this:

\begin{lstlisting}
(*@\jskeyword{if}@*) (*@\jspunct{(}@*)(*@\jscomment{// condition goes here}@*)(*@\jspunct{)}@*) (*@\jspunct{\{}@*)
  (*@\jscomment{// code runs when the condition is true}@*)
(*@\jspunct{\}}@*) (*@\jskeyword{else}@*) (*@\jspunct{\{}@*)
  (*@\jscomment{// code runs when the condition is false}@*)
(*@\jspunct{\}}@*)
\end{lstlisting}

\vspace{0.1cm}

\begin{lstlisting}
(*@\jsobject{selectedAnswer}@*)(*@\jspunct{.}@*)(*@\jsobject{value}@*) === (*@\jsstring{"html"}@*)
\end{lstlisting}

\vspace{0.2cm}

This means: check whether the value of the selected answer is equal to \inlinejsstring{"html"}.

\vspace{0.3cm}

\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Attention Please!}}

  In JavaScript, \inlinejsmethod{===} is used to compare two values.
  It asks: are these two things exactly the same?
\end{attentionbox}

\vspace{0.4cm}

\textbf{\Bitter\textcolor{naranja}{Writing the Full JavaScript Function}}

\vspace{0.1cm}

Now we can place the logic inside the function.

\vspace{0.2cm}

\begin{lstlisting}

\vspace{0.3cm}

This function follows the logic we planned:

\begin{enumerate}[leftmargin=1.2cm, itemsep=4pt]
  \item We find the selected radio button.
  \item We read the selected answer's value.
  \item We compare that value to \inlinejsstring{"html"}.
  \item We show feedback based on the result.
\end{enumerate}

\textbf{\Bitter\textcolor{naranja}{How the Feedback Appears}}

\vspace{0.1cm}

The feedback message appears inside this paragraph from the HTML:

\vspace{0.1cm}

\begin{lstlisting}
(*@\htmltag{<p}@*) (*@\attrname{id}@*)=(*@\attrvalue{"feedback"}@*)(*@\htmltag{></p>}@*)
\end{lstlisting}

\vspace{0.2cm}

JavaScript finds this paragraph by using its \inlineattr{id}:

\vspace{0.1cm}

\begin{lstlisting}
(*@\jsobject{document}@*)(*@\jspunct{.}@*)(*@\jsmethod{getElementById}@*)(*@\jspunct{(}@*)(*@\jsstring{"feedback"}@*)(*@\jspunct{)}@*)
\end{lstlisting}

\vspace{0.2cm}

Then it changes the text inside the paragraph using \inlinejsobject{textContent}.

\vspace{0.3cm}

\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Important Note}}

  JavaScript does not create the feedback paragraph here.
  The paragraph already exists in the HTML.
  JavaScript only finds it and changes the text inside it.
\end{attentionbox}

\vspace{0.4cm}

\textbf{\Bitter\textcolor{naranja}{Triggering the JavaScript Function}}

\vspace{0.1cm}

The last piece is triggering the JavaScript function.

We want the \inlinejsfunction{checkAnswer} function to run when we click the Submit button.
To make that happen, we need to connect the button to the function.

In HTML, when we want something to happen after we click an element, we can use the \inlineattr{onclick} attribute.
The \inlineattr{onclick} attribute tells the browser what JavaScript function should run when that element is clicked.

\vspace{0.1cm}

\begin{lstlisting}
(*@\htmltag{<button}@*) (*@\attrname{onclick}@*)=(*@\attrvalue{"checkAnswer()"}@*)(*@\htmltag{>}@*)(*@\codetext{Submit}@*)(*@\htmltag{</button>}@*)
\end{lstlisting}

\vspace{0.2cm}

In this example, the button says \inlineattr{onclick}=\inlineattrvalue{"checkAnswer()"}.
This means: when we click the Submit button, the browser runs the \inlinejsfunction{checkAnswer} function.

\vspace{0.3cm}

\begin{attentionbox}
  \textbf{\Bitter\textcolor{naranja}{Attention Please!}}

  The \inlineattr{onclick} attribute is commonly used with buttons because buttons are meant to be clicked.
  In our activity, it is the bridge between the HTML button and the JavaScript behavior.
\end{attentionbox}

\vspace{0.4cm}

\textbf{\Bitter\textcolor{naranja}{JavaScript Script Block}}

\vspace{0.1cm}

Just like we can include CSS directly in a page using a \inlinehtmltag{<style>} tag,
we can include JavaScript directly in the same file using a \inlinehtmltag{<script>} tag.

The \inlinehtmltag{<script>} tag tells the browser: everything inside here is JavaScript code
that will run when the page is loaded or when we trigger it (for example, when a button is clicked).

This is useful for small activities like ours because we can keep all the HTML, CSS, and
JavaScript in a single file, making it easy to manage and test.
